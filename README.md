## About this repository

This was my standalone React portfolio from 2024–2025. It contains the earlier hero, skills, projects, interactive terminal, and about-page implementation.

The current portfolio has replaced it with a new interface and an integrated RAG playground that lets visitors ask questions and inspect the retrieved evidence.

Old Vercel links previously associated with this repository are no longer valid for this project. In particular, `yash-portfolio-vert.vercel.app` is **not my website** and is not built from this repository.

## Historical stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router (react-router-dom)
- Vercel Analytics

## Run locally

```bash
git clone https://github.com/Yash456k/Yash_Portfolio.git
cd Yash_Portfolio
npm install
npm run dev
```
